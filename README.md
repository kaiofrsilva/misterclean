🧼 Mister Clean

Landing page institucional desenvolvida para a Mister Clean, com foco em apresentar a marca de forma moderna, profissional e responsiva.

O projeto foi desenvolvido com uma abordagem front-end, priorizando experiência do usuário, organização visual, responsividade e interações utilizando JavaScript.

🚀 Sobre o projeto

O Mister Clean é um projeto de website institucional criado para demonstrar a construção de uma landing page moderna utilizando tecnologias web fundamentais.

A interface foi desenvolvida com foco em:

Design moderno e minimalista
Experiência do usuário
Responsividade para diferentes dispositivos
Animações e interações
Organização e hierarquia visual
Navegação simples e intuitiva
✨ Funcionalidades
Landing page responsiva
Header com navegação
Seção Hero
Botões de chamada para ação
Comparador interativo de imagens "Antes x Depois"
Cards com animações e efeitos visuais
Galeria de imagens
Seção de apresentação do processo
Layout adaptado para dispositivos móveis
Navegação com rolagem suave
Elementos interativos desenvolvidos com JavaScript
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
SVG
Google Fonts
🎨 Interface

O projeto utiliza uma identidade visual moderna, combinando:

Tipografia personalizada
Cards com bordas e sombras
Elementos arredondados
Animações sutis
Layout responsivo
Componentes interativos
Seções organizadas em uma única página
📱 Responsividade

A interface foi desenvolvida para funcionar em diferentes tamanhos de tela, incluindo:

💻 Desktop
💻 Notebook
📱 Smartphones
📱 Tablets

O layout utiliza CSS Media Queries para adaptar os componentes de acordo com a resolução do dispositivo.

🔄 Interatividade

Um dos principais elementos do projeto é o comparador Antes x Depois, desenvolvido com HTML, CSS e JavaScript.

O usuário pode interagir com o controle deslizante para visualizar a diferença entre as duas imagens.
